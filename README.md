# Calibration Error Under Rater Disagreement

Code for the benchmark experiments in:

> **On the Behavior of Calibration Error Under Rater Disagreement**
> - MICCAI 2026

## What this does

Runs synthetic benchmark experiments to study how calibration metrics behave as a function of rater subjectivity. Each "world" is parameterized by `a`, which controls the shape of the latent probability distribution — large `a` places mass near 0 and 1 (high subjectivity), small `a` concentrates mass near 0.5 (low subjectivity).

For each world and each rater count, we compute:

- **CaseECE** — standard ECE using majority vote labels
- **MR-ECE** (Rater ECE) — ECE computed at the individual rater level by flattening annotations and repeating per-case model scores
- **AdjustedECE** — CaseECE after applying a binomial transformation to model scores to account for the majority vote aggregation
- **TVD** — Total Variation Distance between model and human probability distributions

The implementations of AdjustedECE and MR-ECE are in `main.ipynb` (`_compute_metrics`).

## Structure

```
main.ipynb                  # Experiment definition and entry point
dataset_generator/          # Synthetic data generation (bimodal power distribution)
evaluation_metrics/         # ECE and TVD implementations
utils/plot_utils.py         # Plotting utilities
results/                    # Figures reported in the paper (regenerated by main.ipynb)
```

## Usage

```bash
pip install -r requirements.txt
jupyter notebook main.ipynb
```

Configure the `worlds` dict and `n_raters_list` at the bottom of `main.ipynb`, then run all cells. Outputs are saved to `results/`.
